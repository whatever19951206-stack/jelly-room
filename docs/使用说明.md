# 慢慢切 · 果冻小店

双击「慢慢切.html」，用新版 Chrome 或 Edge 打开即可。无需安装、联网或登录。

## 果冻大西瓜

从主菜单进入「果冻大西瓜」。移动鼠标瞄准，按住拖动后松手投下切片；手机也可以拖动瞄准、松手投放。画面下方的左右和投放按钮也能操作。

使用原来小店里的葡萄冻片、蜜橙切片和西瓜切片，共 11 个大小等级。同一级切片碰到一起会融合成更大一级；口味会随等级变化，最后合出大西瓜片。画面里可以看下一片和成长图谱，合成得到分数；合出大西瓜片后仍然可以继续玩。

投放之间有短暂间隔。小果冻可以滚进缝隙，同一级切片在挤压碰撞中也能合成，先看下一颗再选择落点。切片的接触处会压软、回弹，果皮、切面和籽也一起变形。

水果持续堆过上方危险线会触发倒计时，及时融合、把高度降下来就能解除危险；刚丢下、还没落稳的水果有宽容时间。空间不足时这一局结束，可以重开挑战。

- ← / →：左右瞄准。
- 空格或 Enter：投下一颗。
- P 或 Esc：暂停 / 继续。
- M：声音开关。

切换窗口或离开页面会自动暂停，回到页面后点击继续。返回小店保留这一局，再进入可以接着玩；关闭页面后不保留未结束的局。最高分独立保存在当前浏览器，其他游戏的进度分别记录。

## 果冻方块

主菜单点击「果冻方块」，再点「开始这一局」。七种形状轮流下落，填满一整行就消除；每消除 10 行升一级，速度逐渐加快，堆到顶部即结束。果冻落地会压扁回弹，消行后上面的果冻会继续落下、晃动；这些视觉变形不会改变格子规则。

右侧有下一块预览，淡色轮廓表示当前方块的最终落点。暂存可换出当前一块，每次落地后才可再次使用。

| 操作 | 键盘 |
| --- | --- |
| 左右移动 | ← / → |
| 顺时针 / 逆时针旋转 | ↑ / Z |
| 加速下落 | ↓ |
| 直接落到底 | 空格 |
| 暂存 | C |
| 暂停 / 继续 | P 或 Esc |
| 声音 | M |

手机可以使用画面下方的移动、旋转、加速、落下和暂存按钮，也可在棋盘上滑动。切换窗口或离开页面会自动暂停；回到页面后需点击继续。

返回小店会暂停此局，重新进入可以继续；「重开」另起一局。关闭页面后不会保留未结束的一局。最高分保存在当前浏览器，小店的订单、星星和印章独立保存。

## 从第一单开始

点击「开始接单」，看订单要求，再把果冻切成所需分量。

1. 选「切一刀」。在果冻上划一条线，松手下刀；也可以点一下，按当前刀角切。落刀前会显示预计切出的百分比。
2. 选「拽一拽」。点击小块查看它的分量和果皮比例，拖到下方订单盘松手。也可以先点小块，再点订单盘；场景中的实体餐盘也能接住投递。
3. 每个盘子只收一块。放错了就点餐盘取回，继续切；切错了可「撤销」。全部装好后点「交给客人」。
4. 通过后解锁下一单。结算会告诉你分量、刀数和剩余食材的情况；没通过可「继续调整」，保留当前桌面。

百分比按每种口味最初的整块计算。混合订单的「50% 西瓜」和「50% 蜜橙」各指各自原料的一半。拉长、扭转不会增加分量。白边和绿皮都计入西瓜果皮。

## 小店的六章

- 一起分着吃：两份、三份、四份，熟悉切配和装盘。
- 眼睛就是秤：按不同胃口切出不等份量。
- 每一刀都算数：在规定刀数内完成，练习一刀同时切开多块。
- 瓜心与果皮：切出纯瓜心、过渡层与带皮部分。
- 一盘小风景：按指定盘位摆好；轻抛只加分，不妨碍通关。
- 最后一桌客人：两种口味，多份切配，综合毕业宴。

共 24 单、72 颗星、11 枚印章。首轮路线按新手试切与修整设计，预计约 30–50 分钟；熟练玩家可以更快完成。这是设计估算，游戏没有强制等待或通关倒计时。

一星允许适当分量误差；二星要求更准；三星还要求利落的刀法。用时只影响额外分数，慢慢玩也能拿三星。每单的刀数上限是通关要求，超过后可撤销或重做。

「今日练习」按日期生成可复现订单，做完后还能接新的练习；「自由玩」保留无目标的西瓜、蜜橙、葡萄沙盒，随便拽、切、扭转。

## 操作与进度

- 拖住时滚轮可扭转；触屏加第二根手指绕转。
- 切刀模式滚轮、Q / E 或 ↶ ↷ 转刀。
- 手感设置内可调整软糯程度、阻尼、¼ 速度、网格及暂停。
- 快捷键：1 拽、2 切、空格临时切刀、U 撤销、Enter 交单、R 重做、J 晃动、M 声音、H 操作帮助、Esc 回订单册。
- 通关、星星、印章和练习成绩自动保存在当前浏览器。返回订单册或关闭后，未提交订单会从完整原料重新开始。清理浏览器数据或改用另一浏览器会分开记录进度。

需要支持 WebGL 2 的现代浏览器，建议启用硬件加速。触屏浏览器也能操作；部分手机文件管理器不能运行 HTML，需通过浏览器访问托管页面。

最多 36 块，极小切片会保留，避免产生无法拿取的碎屑。成品没有外部资源、广告、登录或数据上传。随附 Three.js MIT 许可证。
